# Client Proof Database Template

Dokumen ini adalah format standar untuk mencatat, menyimpan, dan melacak bukti kerja nyata (*proof*) dari klien Skillary. 

**PENTING: Kebijakan Integritas Skillary**
- Jangan pernah mempublikasikan logo organisasi tanpa izin tertulis/lisan yang jelas.
- Jangan memanipulasi jumlah peserta.
- Jangan menulis testimoni palsu. Gunakan format anonim (berdasarkan sektor) jika klien tidak mengizinkan nama perusahaan dipublikasikan.

---

## Format Tabel Database (Gunakan di Spreadsheet / Notion)

| Kolom | Penjelasan | Contoh |
| :--- | :--- | :--- |
| **Client / Organisasi** | Nama resmi organisasi klien. | PT Maju Makmur Tbk |
| **Sector** | Industri atau bidang usaha klien. | Manufaktur / FMCG |
| **Program Name** | Nama program pelatihan yang dijalankan. | Leadership 101 Bootcamp |
| **Year** | Tahun pelaksanaan program. | 2026 |
| **Topic** | Kategori/Topik utama. | Leadership & Communication |
| **Number of Participants**| Jumlah real peserta yang terdaftar/hadir. | 45 Orang |
| **Format** | Online, Offline, atau Hybrid. | Offline |
| **Photos available?** | Apakah ada dokumentasi foto yang layak? | Yes |
| **Testimonial available?**| Apakah ada kutipan dari peserta/manajemen? | Yes |
| **Logo permission?** | Izin pasang logo di website? (Yes/No) | No |
| **Name permission?** | Izin sebut nama perusahaan? (Yes/No) | Yes |
| **Case study permission?**| Izin dijadikan studi kasus publik? | Pending |
| **PIC** | Nama narahubung internal dari klien. | Bpk. Andi (HR Manager) |
| **Evidence Link** | Link ke folder GDrive/aset dokumentasi. | `gdrive.com/folder123` |
| **Publication Status** | Internal Only / Public / Anonymized | Anonymized |
| **Notes** | Catatan khusus. | Boleh sebut "Perusahaan Manufaktur FMCG", logo dilarang. |

---

## Aturan Publikasi Jika Izin Dibatasi (Anonymized Proof)

Jika klien **TIDAK** memberikan izin untuk menyebutkan nama atau logo mereka, namun program berjalan sukses, gunakan format *anonymized* (nama disamarkan namun data tetap nyata):

**Contoh yang BENAR:**
> "Melatih 45 supervisor dari salah satu perusahaan manufaktur FMCG terbesar di Jawa Barat untuk program Leadership & Communication dengan tingkat kelulusan assessment 92%."

**Contoh yang SALAH (Fake):**
> Memasang logo sembarangan atau mengarang cerita keberhasilan tanpa dasar data.
