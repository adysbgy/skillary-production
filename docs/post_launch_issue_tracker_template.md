# Post-Launch Issue Tracker

Use this template to log bugs, UX issues, and critical failures found in production.

## Severity Definitions
- **P0 (Critical):** Site down, data leak, admin inaccessible, lead form broken. Needs immediate hotfix.
- **P1 (High):** Major conversion blocker, critical admin flow broken. Fix within 24-48 hours.
- **P2 (Medium):** Visual/layout bug, confusing copy, non-critical feature bug. Fix in next sprint.
- **P3 (Low):** Small polish, minor spelling error, slight alignment issue.
