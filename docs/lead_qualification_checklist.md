# Skillary Lead Qualification Checklist

Dokumen ini membantu tim Skillary menilai secara cepat apakah sebuah inkuiri atau *lead* siap untuk dibuatkan proposal, memerlukan *discovery call* lebih lanjut, atau belum sesuai dengan layanan Skillary saat ini.

---

## 1. Sumber Lead (Lead Source)
Identifikasi dari mana calon klien berasal:
- [ ] Website Contact Form
- [ ] WhatsApp Inbound
- [ ] Referral / Rekomendasi
- [ ] Klien Lama (Existing Client)
- [ ] LinkedIn / Direct Message
- [ ] Event / Seminar / Webinar

## 2. Tipe Layanan (Lead Type)
Apa kebutuhan utama calon klien?
- [ ] In-house training (Custom program)
- [ ] Assessment program (Pre/Post-test & evaluasi)
- [ ] Managed learning (Skillary mengelola end-to-end)
- [ ] Platform/LMS discussion (Butuh infrastruktur digital saja)
- [ ] Expert partner (Trainer yang mencari platform/kolaborasi)
- [ ] General inquiry (Hanya tanya-tanya)

## 3. Pertanyaan Kualifikasi (Discovery Questions)
Pastikan informasi berikut terkumpul sebelum menyusun proposal:
- [ ] **Nama organisasi:**
- [ ] **PIC dan jabatan:**
- [ ] **Jumlah peserta:**
- [ ] **Profil peserta:** (Level staf, manajer, atau direksi?)
- [ ] **Topik pelatihan:**
- [ ] **Target output:** (Apa yang ingin dicapai?)
- [ ] **Timeline:** (Kapan program akan dijalankan?)
- [ ] **Format:** (Online / Offline / Hybrid?)
- [ ] **Perlu assessment?** (Pre-test / Post-test)
- [ ] **Perlu sertifikat?**
- [ ] **Perlu laporan peserta?**
- [ ] **Perlu proposal resmi?**
- [ ] **Ada budget range?** (Opsional di awal, tapi penting)
- [ ] **Decision maker siapa?** (Siapa yang menyetujui proposal?)
- [ ] **Deadline pengambilan keputusan?**

## 4. Skor Lead (Lead Scoring)
- **🔥 Hot Lead:** Kebutuhan jelas, budget ada, timeline pasti (dalam 1-2 bulan), decision maker terlibat.
- **☀️ Warm Lead:** Kebutuhan ada, tertarik dengan Skillary, tapi timeline masih rancu atau budget belum disetujui.
- **🌱 Nurture Lead:** Sekadar cari informasi harga, belum ada kebutuhan mendesak.
- **❌ Not Fit:** Kebutuhan di luar layanan Skillary (misal: cari sertifikasi BNSP pemerintah, budget terlalu kecil, dll).

## 5. Rekomendasi Tindakan Selanjutnya
Berdasarkan skor di atas, lakukan langkah berikut:
- [ ] **Kirim Program One-Pager** (Untuk Warm/Nurture Lead yang masih memilih topik).
- [ ] **Jadwalkan Discovery Call** (Untuk mendalami kebutuhan Hot/Warm Lead).
- [ ] **Minta Detail Tambahan via WA/Email** (Jika form kualifikasi belum lengkap).
- [ ] **Siapkan Proposal Resmi** (Jika kualifikasi sudah lengkap dan Hot Lead).
- [ ] **Follow Up dalam 3 Hari Kerja** (Jika belum ada respons setelah mengirim informasi).
