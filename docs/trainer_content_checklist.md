# Trainer Profile Publishing Checklist

- [ ] Identity reviewed
- [ ] Trainer consent recorded
- [ ] Final profile preview approved by trainer
- [ ] Portrait and action images licensed for publication
- [ ] Experience claims sourced
- [ ] Credential issuer/status checked
- [ ] Metrics have internal source notes
- [ ] Testimonials have context and consent
- [ ] HTTPS external links checked
- [ ] Organization references do not imply endorsement
- [ ] Status and last verification date are accurate
- [ ] Accessibility copy and alt text reviewed
